# Reaver Agents — multipage website

Static HTML/CSS/JS website with six pages: Home, Models, Agents, Features, Playground, About.

## Run locally
Open `index.html` in a browser, or run `python -m http.server 8000` in this folder and visit `http://localhost:8000`.

## GitHub Pages
Upload all files and the `assets/` folder to the root of a GitHub repository. In Settings → Pages choose Deploy from a branch, `main`, `/ (root)`.

## Important
The playground is a UI demo. No live AI integrations or billing exist. To enable live models, create a secure backend and integrate providers using server-side API keys. Never put API secrets in client-side JavaScript.

Background images are derived from prior user-requested Reaver concept artwork.
